# 🏙️ Civil City Simulator

**建設コンサルタントとして街を診断・改善する、学べる都市シミュレーションゲーム**

「SimCity × Cities: Skylines × 建設コンサルタント × 都市計画 × 防災 × デジタルツイン」
をコンセプトに、都市計画・インフラ整備・防災・PPP/PFIを楽しみながら学べます。

対象: 建設コンサルタント / 自治体職員 / 学生 / 都市計画担当者

## 📖 概要

プレイヤーは市長ではなく**建設コンサルタント**。
20×20のマップに道路・住宅・商業施設・公共施設・防災インフラを整備し、
AI都市診断の提言を参考にしながら、人口・税収・幸福度・災害リスクなど
15のKPIで評価される都市を育てます。

### 主な機能
- 🗺️ 20×20グリッドの都市マップ（河川自動生成）
- 🏗️ 15種類の建物・インフラ（住宅〜調整池・防災公園まで）
- 🚗 交通シミュレーション（渋滞・道路網評価・公共交通）
- 🌉 インフラ老朽化とLCC（ライフサイクルコスト）
- 🌊 災害シミュレーション（洪水・地震・土砂災害）＋ハザードマップ
- 🤝 PPP/PFI・Park-PFI政策による都市経営
- 🤖 AI都市診断（「北側は病院不足です」「橋梁更新を推奨します」）
- 📊 15指標のKPIダッシュボード（B/C・公共施設充足率・CO2など）

## 🚀 使い方

ES Modulesを使用しているため、ローカルサーバーで起動してください。

```bash
# リポジトリを取得
git clone <このリポジトリのURL>
cd calculator/civil-city-simulator

# 方法1: Python
python3 -m http.server 8000

# 方法2: Node.js
npx serve .
```

ブラウザで `http://localhost:8000` を開くとゲームが始まります。

### 遊び方
1. **左メニュー**から建物を選択し、**中央マップ**をクリックして建設
2. まずは道路を敷き、道路沿いに住宅・商業施設を配置
3. 「次のターン」ボタン（または▶で自動進行）で時間を進める
4. **右パネル**のKPIとAI診断を見ながら都市の課題を改善
5. 川沿いには堤防、山際は開発を控えるなど防災も忘れずに
6. 維持費が重くなってきたら 🏛️ ボタンからPPP/PFIを導入

### 操作
| 操作 | 内容 |
|------|------|
| 建物アイコンをクリック → マップをクリック | 建設 |
| 🚧撤去 → 建物をクリック | 撤去（¥10M） |
| ⏭ 次のターン | 手動でターン進行 |
| ▶ / ▶▶ | 自動進行（3秒/1.5秒ごと） |
| 🗺️ | ハザードマップ表示切替 |
| 🏛️ | PPP/PFI政策メニュー |
